# AIライティングツール

Streamlit と Gemini API で作った、個人用のAIライティングツールです。

## 機能

| ツール | 内容 |
| --- | --- |
| 📝 ブログ記事作成 | テーマ・キーワードから見出し付きの記事、または構成案を作成 |
| ✉️ メール作成・返信 | 受信メールへの返信や新規メールを、相手との関係・トーンに合わせて作成 |
| 📋 要約 | 箇条書き・3行要約などの形式と長さを指定して要約 |
| 🔍 校正・推敲 | 誤字脱字や文法を直し、修正点の一覧も出力 |
| 🔄 リライト・言い換え | ビジネス調・やさしく・簡潔になど、スタイルを変えて書き直し |
| 🌐 翻訳 | 多言語への翻訳（意訳・直訳・ビジネス向けなど） |
| 💡 タイトル・キャッチコピー | タイトル・件名・コピーの案をまとめて出し、おすすめを選定 |
| 📣 SNS投稿 | X・Instagram・LinkedIn など媒体に合わせた投稿文 |
| 🗒️ 議事録作成 | メモや文字起こしから、決定事項と TODO を整理した議事録 |
| 🧠 アイデア出し | 記事ネタや企画のアイデア出しと、次の一歩の提案 |
| 💬 フリーチャット | 上記にない依頼や文章の相談を対話形式で |

どのツールでも、生成結果に「もっと短く」などの修正指示を出して作り直せます（以前のバージョンも残ります）。
結果はコピー用テキストの表示や、Markdown ファイルでのダウンロードができます。

## セットアップ

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # .env に GEMINI_API_KEY を記入
streamlit run app.py
```

APIキーは [Google AI Studio](https://aistudio.google.com/apikey) で発行できます。
`.env` に書かない場合は、起動後にサイドバーから入力することもできます。

## ファイル構成

- `app.py` — 画面（Streamlit）
- `writing_tools.py` — 各ツールの入力項目とプロンプト。ツールを増やすときは `TOOLS` に追加
- `gemini_client.py` — Gemini API の呼び出し
